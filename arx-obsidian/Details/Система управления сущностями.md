### Основные положения. Что мы хотим от системы?
1. Система должна поддерживать выполнение сразу нескольких последовательностей для разных сущностей.
2. Последовательности должны иметь возможность иметь ветвления.
3. Система должна корректно обрабатывать выход игрока из мира.
4. В основном система будет использоваться в сюжете для управления уникальными сущностями, например их хождением в сюжете по локациям.

### Реализация. Как это сделать?
- Система будет представлять из себя вручную прописанные списки последовательностей передвижения и действий сущностей, хранящиеся в sequences в NPCManager.js, их реализацию и валидацию.
- Статус выполнения последовательности должен храниться на сущности. На этой сущности сохраняется offset для последовательности - обычно anchor локации, в которой она находится, id последовательности и ее активный шаг. 
- Единственный образец класса NPCManager содержит в себе все активные последовательности, назначенные на все прогруженные сущности в данный момент.
- В один момент у одной сущности может быть только одна назначенная последовательность.
- Должны быть способы зарегистрировать последовательность на сущность: При ее загрузке (worldAfterEvents.entityLoad) и прямым назначением (e.setActiveSequenceId())
