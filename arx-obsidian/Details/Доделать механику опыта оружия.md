Есть смысл добавить возможность отравлять оружие ядом скорпиона или зельем яда

Система опыта оружия:
Оружие может получать опыт, который хранится в DP ItemStack.

Получение опыта зависит от урона, нанесенного оружием, или траты маны с этим оружием в руках. 1 ед. опыта примерно равно 5 ед. урона, или 10 потраченным ед. маны. 

Оружие крафтится с 0 уровнем. 1 уровень на 20 опыта, 2 на 40, 3 на 80 и т.д.

Каждый уровень игрок может выбрать один из двух случайных навыков:
```js
const weaponSkills = {
  damage:        { description: '+1 basic damage' },
  handy:         { description: '-1 Weight' },
  balanced:      { description: '+10% speed while holding it' },
  painful:       { description: 'Melee attack applies blindness to the opponent for 5 sec. CD 1 min' },
  massive:       { description: 'Slows opponent for 3 sec on hit. CD 30 sec' },
  repair:        { description: 'Instantly repairs the weapon' },
  'rat slayer':  { description: 'Deals additional damage to rats' },
  'soul stealer':{ description: 'Slightly heals you when dealing damage' },
  training:      { description: 'You upgrade battle and magic skills faster when using it' },
  explosive:     { description: 'Creates an explosion on attack with 10% chance.' },
  destructive:   { description: 'Replaces blocking with ability to dash at enemy' },
  obsessive:     { description: 'On attack: blinds you, but grants +6 basic strength for 10 sec. CD 5 min' },
  poisoned:      { description: '10% chance to apply poison for 5 sec' },
}
```

### Имя создателя на оружии
/clearWeaponName - удалить имя создателя оружия. Возможно сделать только в случае, если вы - истинный создатель оружия
/restoreWeaponName - вернуть имя создателя оружия. Возможно сделать только в случае, если вы - истинный создатель оружия. Будет установлен никнейм игрока в локальном чате в имя создателя меча.
